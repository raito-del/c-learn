# C শিখি

ধাপে ধাপে C প্রোগ্রামিং শেখার একটি ওয়েবসাইট। একদম প্রথম থেকে শুরু করে মিড লেভেল পর্যন্ত, প্রতিটা টপিকে থিওরি, কোড স্ট্রাকচার, উদাহরণ, MCQ আর প্র্যাকটিস আছে।

## বৈশিষ্ট্য

- প্রতিটা টপিকে বাংলায় থিওরি ও ব্যাখ্যা
- কোড স্ট্রাকচার: কোডের প্রতিটা অংশ ধাপে ধাপে ব্যাখ্যা
- উদাহরণ কোড, যেটা ব্রাউজারেই চালানো যায়
- MCQ: উত্তর দেওয়ার সঙ্গে সঙ্গে ঠিক বা ভুল দেখায়
- প্র্যাকটিস: প্রশ্ন, সম্ভাব্য আউটপুট, এবং নিজে কোড লিখে যাচাই
- অগ্রগতি ব্রাউজারে সেভ থাকে
- মোবাইল ও ল্যাপটপ, দুই জায়গাতেই ব্যবহারযোগ্য

## প্রযুক্তি

- HTML, CSS, JavaScript
- কোড চালানোর জন্য [JSCPP](https://github.com/felixhao28/JSCPP), যেটা ব্রাউজারের ভেতরেই C কোড ব্যাখ্যা করে চালায়
- হোস্টিং: GitHub Pages

কোনো সার্ভার, ডেটাবেস বা ইনস্টলেশন লাগে না।

## ফোল্ডার কাঠামো

```
c-learn/
├── index.html          মূল পেজ
├── css/
│   └── style.css       ডিজাইন ও লেআউট
├── js/
│   └── engine.js       নেভিগেশন, ট্যাব, রান, যাচাই, অগ্রগতি
├── topics/
│   ├── t01.js          টপিক ১: C কম্পাইল ও প্রথম প্রোগ্রাম
│   ├── t02.js          টপিক ২: ভেরিয়েবল ও ডেটা টাইপ
│   └── ...             মোট ২০টি টপিক
└── README.md
```

## নতুন টপিক যোগ করা

1. `topics/` ফোল্ডারে নতুন ফাইল বানাও, যেমন `t03.js`।
2. ফাইলের ভেতরে টপিকের তথ্য `window.TOPICS` তালিকায় যোগ করো।
3. `index.html`-এ একটা `<script>` লাইন যোগ করো, যেমন `<script src="topics/t03.js"></script>`।

## লোকালি চালানো

`index.html` ফাইলটি ব্রাউজারে সরাসরি খুললেই কাজ করবে। এর জন্য কিছু ইনস্টল করতে হয় না।

## GitHub Pages-এ প্রকাশ

1. রিপোজিটরি **Settings → Pages**-এ যাও।
2. **Deploy from a branch** সিলেক্ট করো, Branch হিসেবে **main**, folder হিসেবে **/ (root)** রাখো।
3. **Save** চাপো। কয়েক মিনিট পর সাইট খুলবে:
   `https://তোমার-username.github.io/c-learn/`

## সমস্যা হলে

- পেজ খালি দেখালে ব্রাউজারে F12 চেপে Console ট্যাবের লাল এরর দেখো।
- কোনো টপিক না দেখালে `index.html`-এ সংশ্লিষ্ট `<script>` লাইন আছে কি না দেখো।
- নতুন পরিবর্তন না দেখালে ব্রাউজারের ক্যাশ পরিষ্কার করে পেজ আবার খোলো।

## সীমাবদ্ধতা

- JSCPP আসল `gcc` নয়, তাই কিছু উন্নত ফিচার বা এরর মেসেজ আলাদা হতে পারে।
- অসীম লুপের জন্য এখনো টাইমআউট নেই।
- অগ্রগতি শুধু যে ব্রাউজারে শেখা হচ্ছে সেখানেই সেভ থাকে।
